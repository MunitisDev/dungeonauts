# Dungeonauts — Project Brief

## One-sentence pitch
A child-friendly dungeon crawler where players explore, fight monsters, open doors, discover treasure, and progress by solving age-appropriate mathematics and language challenges.

## Product vision
Dungeonauts should make a child think:

> “I am going on an adventure.”

not:

> “I am doing homework.”

Educational tasks are part of the fantasy world and directly cause game actions.

Examples:
- solve a math problem → attack succeeds
- complete a word → spell activates
- answer correctly → door unlocks
- solve a sequence → chest opens
- identify the correct sentence → trap is disabled

## Initial audience
Approximate primary audience: **6–11 years old**

Likely devices:
- desktop/laptop
- Chromebook
- tablet
- potentially mobile later

## Initial subjects

### Mathematics
- counting
- addition
- subtraction
- multiplication
- division
- number sequences
- comparisons
- simple word problems
- basic geometry

### Language
The system should support Spanish and English learning content:
- vocabulary
- spelling
- sentence completion
- word recognition
- synonyms / antonyms
- simple grammar
- reading comprehension
- sentence ordering

## Language support
Initial locales:
- Spanish
- English

Do not hardcode UI or educational content into gameplay logic.

## Emotional tone
Should feel:
- adventurous
- playful
- slightly mysterious
- rewarding
- humorous
- safe
- approachable

Should not feel:
- scary
- violent
- academically punitive
- visually cluttered
- babyish

## Visual identity
Approved direction:
**friendly modern retro pixel art**

Key qualities:
- top-down dungeon
- limited palette
- dark cool dungeon colors
- warm bright interactables
- cute cartoon characters
- friendly monsters
- clean 8/16-bit influence
- simple readable shapes
- no realism
- no horror

See `docs/art/ART_DIRECTION.md`.

## Core design principle
Every educational challenge should answer:

> “Why am I solving this?”

Usually because the player wants to:
- open a door
- defeat/pass an enemy
- obtain treasure
- activate a rune
- continue exploring

## MVP goal
Create a polished vertical slice proving that:
1. dungeon exploration is fun and readable;
2. challenges do not break immersion;
3. solving them creates satisfying in-world feedback;
4. the chosen visual style works in-game;
5. content supports Spanish and English;
6. new questions and assets can be added without rewriting core systems.
